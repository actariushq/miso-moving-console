# miso-moving-console — DB 셋업

DB 스키마는 이미 적용돼 있음 (2026-10-01). 이 폴더로 할 일은 **① 계정 15개 생성**, **② 앞으로 스키마 변경을 마이그레이션으로 관리**할 수 있게 CLI 연결.

## 0. VS Code로 열기 (맥 터미널)
```bash
cd ~/Downloads && unzip -o miso-moving-console_20261001-0631.zip -d ~/ && cd ~/miso-moving-console
code .          # 'code' 명령이 없으면: open -a "Visual Studio Code" .
```

## 1. VS Code 터미널 (Ctrl + `) 에서
```bash
npm install
cp .env.example .env          # .env 열어서 SUPABASE_SERVICE_ROLE_KEY= 뒤에 키 붙여넣고 저장
npm run accounts              # mv1~mv15 생성 → 표에서 전부 '생성' 확인
```
- 매핑: mv1 손홍탁 · mv2 손재혁 · mv3 이지웅 · mv4 황선혜 · mv5 정찬영 · mv6 이상인 · mv7 권도윤 · mv8 이희원 · mv9 석진후 · mv10 박주희 · mv11 이성연 · mv12 지인호 · mv13~15 예비
- 초기 비밀번호는 실행 시 INITIAL_PASSWORD 환경변수로 지정, 전원 operator 권한. 다시 실행해도 안전

## 2. Supabase CLI 연결 (스키마를 코드로 관리)
```bash
npx supabase login            # 브라우저로 로그인
npm run db:link               # DB 비밀번호 물어보면 입력 (Settings → Database 에서 재설정 가능)
npm run db:mark-applied       # 이미 대시보드로 적용한 2개를 '적용됨'으로 기록 (다시 실행되지 않게)
npm run db:status             # Local/Remote 둘 다 20261001000000, 20261001000100 이면 완료
```
이후 스키마 변경: `supabase/migrations/` 에 새 .sql 추가 → `npm run db:push`
